# Todo List

Application de liste de tâches (to-do) construite en React + TypeScript. Ajout, complétion et suppression de tâches, avec une interface épurée.

## Stack

React 19 · TypeScript · Vite · Tailwind CSS v4

## Démarrage

```bash
npm install
npm run dev
```
